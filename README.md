### 🧠 What I'm about

I take complex, data-heavy systems — the kind with ten entity types and a thousand edge cases — and make them feel simple to use. Four years doing that for enterprise and e-commerce products. Lately I've been pulling the backend into my own hands too: architecture, databases, queues, payments — not just the pixels.

Right now: building a **commerce platform engine** — a Turborepo monorepo you can spin up fresh for a new client in minutes, each one with its own theme, its own database, its own deploy. Not a page builder. A real foundation.

---

### 🔥 Currently building

- 🏪 **Commerce platform engine** — NestJS · Next.js · PostgreSQL · Redis · Docker. Spin up a fully-branded storefront per client from one shared codebase — RBAC, auth, payments, and inventory logic built once, reused everywhere.
- 📈 **Multi-exchange trading desk** — connect multiple exchange accounts, one unified view of order books, charts, and execution. Built for speed: keyboard shortcuts, click-to-place orders.
- 🧩 Small lessons, real-world debugging notes, and things I wish I'd known earlier — posted as I go.
